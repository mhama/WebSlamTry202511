# WebAR VISLAM Demo

スマートフォンのバックカメラとセンサーを使用したWebベースのAR（拡張現実）デモです。

## 特徴

- **カメラアクセス**: スマートフォンの外カメラ（リアカメラ）を使用
- **センサー統合**: ジャイロスコープ、加速度センサー、磁力計を使用した簡易VISLAM風のトラッキング
- **3D表示**: Three.jsを使用した3Dオブジェクトの表示
- **インタラクティブ**: タップでAR空間に新しいオブジェクトを配置可能

## 技術スタック

- Three.js (r128) - 3Dグラフィックス
- Device Orientation API - デバイスの向き検出
- Device Motion API - 加速度センサー
- getUserMedia API - カメラアクセス

## 使い方

1. HTTPSでホストされたページにアクセス（GitHub Pagesなど）
2. 「AR開始」ボタンをタップ
3. カメラとセンサーの権限を許可
4. デバイスを動かしてAR空間を探索
5. 「オブジェクト配置」ボタンで新しい3Dオブジェクトを追加

## 必要な環境

- HTTPS接続（カメラアクセスに必須）
- スマートフォン（ジャイロスコープ、加速度センサー搭載）
- モダンブラウザ（Chrome、Safari、Firefoxなど）

## 制限事項

- 本格的なVISLAMではなく、センサーベースの簡易トラッキング
- 視覚的な特徴点マッチングは未実装
- 環境マッピングは簡易的

## デバッグ機能

右上の「デバッグON/OFF」ボタンで詳細なデバッグ情報を表示できます：

- **システム状態**: カメラ、Three.js、センサーの動作状況
- **FPS**: フレームレートの表示
- **カメラ位置・回転**: リアルタイムのカメラトラッキング情報
- **センサーデータ**: ジャイロスコープと加速度センサーの生データ
- **オブジェクト**: 配置された3Dオブジェクトの位置情報
- **レンダリング**: Three.jsのレンダリング統計
